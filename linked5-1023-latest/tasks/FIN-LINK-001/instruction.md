# 新英格兰三州银行：季度信用复核与八个核查名额分配

你是区域银行信用复核团队的分析师。委员会只有八个银行核查名额，需要先判断三州观察到的变化是否反映同一批银行的恶化，再分配核查资源。这是使用冻结公共数据的回顾性桌面演练，不是当下银行信用评级或投资建议。

使用CSV中的全部VT、NH、ME记录。季度范围以金融CSV实际提供的2022-03-31至2025-06-30为准；重点比较2024-06-30与2025-06-30。金融数据按CERT+REPDTE识别银行季度；机构资料按CERT连接，必须检查连接基数。机构资料是更晚的快照，ACTIVE不能作为删除历史银行或回填历史经营状态的依据。名称不能代替主键。

本练习金额字段ASSET、DEP、EQ、LNLSGR、LNRE、P9ASSET、NAASSET等按千美元处理；ROA、RBCRWAJ等原始比率为百分数，不要重复乘100或把已年化ROA再年化。定义“逾期/非应计资产代理率”=100×(P9ASSET+NAASSET)/ASSET，作为本次核查排序代理，不称作监管评级、不称作贷款不良率。另列房地产贷款占比100×LNRE/LNLSGR、权益/资产100×EQ/ASSET、原始ROA和资本比率RBCRWAJ；缺失和零分母单列，不擅自补0。

工作要求：
1. 从FDIC文档页定位实际引用的金融/机构字段定义网页或文件，核对上述字段含义；列出关键字段的定义来源、金额假设和比率口径。记录金融CSV真实季度数、银行数、缺失季度、重复键及机构连接情况。
2. 计算全季度、各州和区域的代理率：采用分子之和/ASSET之和，不能平均各银行百分数。重点列两个端点的银行明细与各州/区域结果。
3. 另取两个端点都有有效数据的固定银行集合，以2024-06-30资产固定为权重，分别计算两个端点的代理率及变化（百分点）；各州归属按2025-06-30州别固定。与端点观察口径比较，列明进入/退出银行及其金额规模，将剩余差异称作范围和权重变化影响，不做无依据的因果拆分。
4. 分配八个互不重复的核查名额：在2025-06-30代理率有效的银行中先为VT、NH、ME各选代理率最高者，再从未选银行按代理率降序补足八个；同率按CERT数值升序。给每家列当期指标、可获得的上年同季对比、原始记录定位、为什么值得查，以及针对贷款逾期/分类、房地产集中、盈利或资本的具体补证。代理指标高不直接等于银行违规或将倒闭。
5. 使用FDIC贷款手册解释最重要的复核关注点及代理指标的局限，给委员会区分“已算出的事实”“待查原因”“建议行动”，不要引用材料没有给出的监管阈值。

## 委员会后续换期和数据更正

委员会需要在收到文件后，换比较季度、调整核查容量，并在查证后更正工作簿内的金额。请将credit_review.xlsx做成可复用的计算模型：计算依靠工作簿内部公式，不依赖重新运行Python、宏、外链、联网或手工粘贴结果。LibreOffice Calc和常见Python办公库均已安装。

ControlPanel提供三个可编辑、工作簿级命名输入：WF_START_PERIOD默认20240630，WF_END_PERIOD默认20250630（均为原金融CSV实际存在的YYYYMMDD整数季度，且起点小于终点）；WF_REVIEW_SLOTS默认8，可取3–12的整数。默认值完成原题；换期时将原题所有端点、共同银行集合、起点资产固定权重及最新州别改为当前所选季度，不能继续用默认银行集合或2024年资产。各州覆盖顺序固定VT、NH、ME，之后按全域代理率降序、CERT升序补足当前名额，不重复。换期后的“对比”指当前起点和终点；只有默认期间才称同比。

RawFinancials保留746行原金融CSV的完整本地副本，表头为原字段名、行顺序与原CSV一致；可在最左增加source_row，但不得排序或插入汇总行。接收人只更改其中ASSET、P9ASSET、NAASSET的数值，不改CERT、REPDTE、州别或其他原始字段。允许更正为非负数或留空；ASSET为0或空、分子任一项为空的银行季度不能参与代理率、聚合、共同集合或当期排序，必须在DataAudit显式报告。有效数值0与缺失不同；不把空P9ASSET当0。原件始终不改。保留一份不可编辑的原始对照或等价校验，工作簿须识别修订，不能仅依赖接收人手动勾选“已更正”。BankQuarter、PeerQuarter、EndpointBridge、Priority均从当前本地副本计算。

为接收方自动读取程序，提供以下工作簿级命名输出；可选择任意表内布局：

- 对每个组ALL、ME、NH、VT，直接引用EndpointBridge的单元格：WF_OBS_START_组、WF_OBS_END_组、WF_OBS_CHANGE_组、WF_FIXED_START_组、WF_FIXED_END_组、WF_FIXED_CHANGE_组、WF_RESIDUAL_组（单位均为百分数/百分点），以及WF_COMMON_N_组、WF_ENTERING_N_组、WF_EXITING_N_组、WF_ENTERING_ASSETS_组、WF_EXITING_ASSETS_组（资产单位千美元）。进入/退出沿用原题各组两个有效端点的集合差，不将缺失行当作零资产银行。
- WF_PRIORITY_1至WF_PRIORITY_12直接引用Priority的CERT单元格，按上述分配顺序；超出当前名额的项为空，WF_PRIORITY_COUNT为实际分配数。Priority同时展示当前期和可得起点的原始行号及指标，原始RBCRWAJ为0时保留0、标记需核实适用/报告口径，不擅自转缺失或断言资本为零。
- WF_MODEL_VALID为布尔值。季度不存在、起点不早于终点、名额不是3–12整数，或有效终点不足当前名额/缺少任一州时为FALSE；同时清空所有WF_PRIORITY_i，WF_PRIORITY_COUNT为0，并在界面说明输入需修正。不得保留上一份可执行名单。有效输入下为TRUE。
- WF_RAW_UNCHANGED仅在当前三项金额逐行与原始CSV完全一致（含区分空和数值0）时为TRUE。WF_SNAPSHOT_CURRENT仅在三个输入均为默认且原始金额未修订时为TRUE。Word和CSV为默认参数、原始金额的静态快照；界面说明参数或金额变化后须重新导出，不能声称静态文件已自动更新。恢复所有默认输入及原始金额后，两项状态能恢复TRUE。

金额更正只是接收方核实后的内部工作副本情景，不应改变官网字段定义，也不代表公共数据原件有错。默认参数、原始金额下三份交付仍须完成原题并一致；更正后的分析需要沿用同样的审慎解释。只放公式字符串或预先算好的几种场景不能替代实际改值重算。

仅将最终交付文件写入 `/app/output/`。文件名精确如下，不需要另交代码、JSON或过程日志。
