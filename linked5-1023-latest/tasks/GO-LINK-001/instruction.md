# 培训会务预算与审批建议

你是美国农业部（USDA）的会务协调员，负责筹备一次集中培训。请根据差旅规定、公开可核实的行程和费用信息，比较候选地点与参训人数，向负责人提交可供审批的会务方案。

培训时间为2026年11月29日至12月1日。考虑到行程劳累，建议提前一天抵达、培训结束次日返回。具体抵返日期、航班及是否中转由你规划，并说明依据。

本次集体出发地为USDA华盛顿总部：1400 Independence Avenue SW, Washington, DC 20250，出发机场为罗纳德·里根华盛顿国家机场（DCA）。参训人数有18人、24人两种选择，候选培训地点如下。

|---|---|---|

往返机票、住宿、当地交通及培训场地费用由你查询并形成预算估算。记录来源、查询日期和价格适用条件；无法取得的报价应明确标注待询价，不得虚构报价、余票或已确认的预订。住宿按每人单间、含早餐安排，住宿税暂按可报销住宿金额的12%作内部预算估算，该比例不代表当地实际税率。

注册费每人180美元，包含11月29日、11月30日和12月1日午餐。机构另行提供11月28日晚餐、12月1日晚餐及12月2日午餐，相关费用纳入会务预算。培训间歇提供咖啡、水果等茶歇。无人提出饮食例外申请，也未取得超标准实际费用报销授权。酒店及场地的资质、采购安排与资金可用性尚未完成核验。

## 负责人需要作出的决定

应急储备按基础费用小计的5%计算，各方案含储备的总额不得超过53,000美元。在符合预算和差旅规定的前提下，优先安排更多参训人员；人数相同时，选择含储备总额较低的方案，完全并列时按城市英文名顺序确定。

请给出推荐、备选及批准前提，并评估往返机票在当前估算基础上上涨20%的影响。无法执行、超出预算或依据尚不充分的情况，应给出明确的处理建议。关键金额和合规判断须可追溯至相应来源。

## 交付物

请提交以下三个文件。

**conference_budget.xlsx**：用于方案比较和后续调整的预算工作簿。包含Daily、Options、Sources工作表，分别呈现各候选地逐日预算明细、候选方案及压力情景、资料依据与预算口径。金额显示到美分，汇总与明细能够核对。

工作簿应设置便于负责人修改的参数区。预算上限、票价调整系数、储备比例、11月29日早餐安排及抵返日期改变后，相关预算、可行性和推荐结果应自动更新。布局和公式实现可自行选择，不要求特定命名区域。

| 可调整事项 | 交付时采用值 | 回算范围 |
|---|---|---|
| 批准预算上限 | 53,000美元 | 0至100,000美元，包含储备 |
| 票价调整系数 | 1 | 0.5至2；压力情景仍基于调整后的票价上涨20% |
| 应急储备比例 | 5% | 0至20%，适用于基础费用小计 |
| 11月29日政府提供早餐 | 否 | 是或否；改为“是”时不新增采购费用 |
| 抵达及返程日期 | 由推荐行程确定 | 可调整，但须完整参加培训；培训及统一供餐日期保持不变 |

**approval_brief.docx**：面向负责人的简明审批建议，说明推荐、备选、关键金额、行程依据、机票上涨时的应对安排及执行条件。

**approval_register.csv**：UTF-8审批与补证登记表，包含事项、拟负责角色、所需证据、建议完成期限及是否阻断批准，与审批建议一致。

Word和CSV作为交付时推荐行程及参数的快照。工作簿应提示参数变更后需要重新核对并导出相应文件，避免将旧文档误作当前结论。
