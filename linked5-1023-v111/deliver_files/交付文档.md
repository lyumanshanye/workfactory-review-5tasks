## 环境变量

| Key | 必选 | 默认值 | 类型或取值 | 说明和联动 |
| --- | --- | --- | --- | --- |
| JUDGE_API_KEY | 是 | 运行环境注入 | string | 由固定test.sh派生Anthropic和OpenAI兼容凭据；题包不含真实密钥 |
| JUDGE_BASE_URL | 是 | 运行环境注入 | URL | Anthropic地址由模板剥除末尾/v1；OpenAI兼容地址保留输入值 |
| JUDGE_MODEL | 否 | qwen3.7-plus | 模型名称字符串 | 通过REWARDKIT_MODEL覆盖rubrics.toml的兜底模型 |
| JUDGE_PROVIDER | 否 | anthropic | anthropic或openai | 信息性声明，不改变路由 |
| JUDGE_API_PROTOCOL | 否 | anthropic | anthropic或openai | anthropic使用Claude Code agent judge；openai由固定模板降级为LLM judge，不能据此宣称完成agent judge验收 |
| EVAL_API_KEY | 否 | 空 | string | 仅在JUDGE_API_KEY未注入时兜底 |
| EVAL_API_BASE | 否 | 空 | URL | 仅在JUDGE_BASE_URL未注入时兜底 |
| LITELLM_DROP_PARAMS | 否 | true | bool字符串 | 网关参数兼容开关 |
| CHROMIUM_EXECUTABLE | 否 | /usr/bin/chromium | 容器内路径 | 镜像设定的Chromium入口，可由Python Playwright显式使用 |

test.sh派生的ANTHROPIC_*、OPENAI_*、REWARDKIT_MODEL和条件性的REWARDKIT_JUDGE不需写入任务环境。CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1、IS_SANDBOX=1由固定模板设置；IS_SANDBOX用于允许容器内root运行非交互判官。镜像预装Claude Code 2.1.114和RewardKit 0.1.7；Python文档依赖在requirements.txt中固定版本。

单个judge会话超时7200秒，verifier总超时18000秒，agent超时72000秒。这些值写入TOML，没有环境变量覆盖接口。CPU 2核、内存8192MiB、存储30720MiB均采用规范默认值。
