# 交付文档

批次 `work_linked5_1023forcodex`，共五题（GO/FIN/LAW/DA/GA），每题三份业务交付。完整模型可见材料及人工审阅入口见 [REVIEW.md](REVIEW.md)。原始种子来自用户指定public_lib和fedcache；使用到的原始下载文件/ZIP成员未改写，新增一手网页保留原始字节、来源与哈希。场景预算、机构事件和运营目标都是题面显式假设，未伪装成真实来源记录。

## 运行约定

每题环境构建上下文为 `environment/`，Dockerfile提供Python3.12、办公解析工具、LibreOffice、中文字体、Claude Code 2.1.114及harbor-rewardkit 0.1.7。输入为只读 `/app/input_files/`；工作目录 `/app`；唯一交付目录 `/app/output/`。普通模型只收instruction和input_files；Oracle才挂solution；判分时才挂tests。配置中的JUDGE变量仅在verifier阶段注入。

`solution/solve.sh` 运行作者可复算候选解。`solution/golden_output/` 与 `tests/__golden_output/` 逐字节一致，但“golden_output”只是规范目录名，当前不代表独立专家认证。

`tests/test.sh` 和 `tests/finalize.py` 逐字复制10月9日规范附录；prompt保留criteria占位符和参考解使用政策。每条criterion采用独立Claude Code会话，由RewardKit逐条串行判分；可按题并行。judge为qwen3.7-plus、单条超时7200秒，verifier总超时18000秒，agent超时72000秒。不存在统一25分钟上限。

## 环境变量

| Key | 必选 | 默认 | 类型和说明/联动 |
|---|---|---|---|
| JUDGE_API_KEY | 判分时是 | 运行时注入 | string；网关凭据，仅verifier可见，test.sh派生底层协议变量 |
| JUDGE_BASE_URL | 判分时是 | 运行时注入 | URL；可带/v1，test.sh派生Anthropic/OpenAI地址 |
| JUDGE_MODEL | 否 | qwen3.7-plus | 模型字符串；派生REWARDKIT_MODEL覆盖配置模型 |
| JUDGE_PROVIDER | 否 | anthropic | anthropic/openai；信息声明，不改变执行 |
| JUDGE_API_PROTOCOL | 否 | anthropic | anthropic使用Claude Code；openai改用降级LLM judge |
| EVAL_API_KEY / EVAL_API_BASE | 否 | 空 | 旧兼容回退；JUDGE变量存在时优先使用JUDGE |
| LITELLM_DROP_PARAMS | 否 | true | bool字符串；网关兼容 |
| REWARDKIT_MODEL / REWARDKIT_JUDGE | 否 | test.sh派生 | 运行时模型/判官覆盖；不注入被测模型 |
| ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN / ANTHROPIC_API_KEY | 否 | test.sh派生 | 来自JUDGE变量；不写入题包凭据 |
| OPENAI_API_KEY / OPENAI_BASE_URL / OPENAI_API_BASE | 否 | test.sh派生 | 协议兼容字段；同样仅判分阶段 |
| CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC | 否 | test.sh设置1 | 减少CLI附加流量 |
| IS_SANDBOX | 否 | test.sh设置1 | 容器内root执行Claude Code所需 |
| LITELLM_LOCAL_MODEL_COST_MAP | 仅离线验证 | True | 原生配置预检/离线环境检查使用本地模型价格表；不改变题目或judge评分 |

单条judge和verifier超时不支持环境变量覆盖；修改需更改toml并重交版本。标准资源为2CPU/8192MiB/30720MiB，网络public用于框架安装；任务本身不需要联网更新资料。新环境构建将Debian源改为HTTPS，避免当前主机HTTP大文件下载停滞。
