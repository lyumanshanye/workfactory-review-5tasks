# 新英格兰三州银行：季度信用复核与八个核查名额分配

你是区域银行信用复核团队的分析师。委员会只有八个银行核查名额，需要先判断三州观察到的变化是否反映同一批银行的恶化，再分配核查资源。这是使用冻结公共数据的回顾性桌面演练，不是当下银行信用评级或投资建议。

使用CSV中的全部VT、NH、ME记录。季度范围以金融CSV实际提供的2022-03-31至2025-06-30为准；重点比较2024-06-30与2025-06-30。金融数据按CERT+REPDTE识别银行季度；机构资料按CERT连接，必须检查连接基数。机构资料是更晚的快照，ACTIVE不能作为删除历史银行或回填历史经营状态的依据。名称不能代替主键。

本练习金额字段ASSET、DEP、EQ、LNLSGR、LNRE、P9ASSET、NAASSET等按千美元处理；ROA、RBCRWAJ等原始比率为百分数，不要重复乘100或把已年化ROA再年化。定义“逾期/非应计资产代理率”=100×(P9ASSET+NAASSET)/ASSET，作为本次核查排序代理，不称作监管评级、不称作贷款不良率。另列房地产贷款占比100×LNRE/LNLSGR、权益/资产100×EQ/ASSET、原始ROA和资本比率RBCRWAJ；缺失和零分母单列，不擅自补0。

工作要求：
1. 从FDIC文档页定位实际引用的金融/机构字段定义网页或文件，核对上述字段含义；列出关键字段的定义来源、金额假设和比率口径。记录金融CSV真实季度数、银行数、缺失季度、重复键及机构连接情况。
2. 计算全季度、各州和区域的代理率：采用分子之和/ASSET之和，不能平均各银行百分数。重点列两个端点的银行明细与各州/区域结果。
3. 另取两个端点都有有效数据的固定银行集合，以2024-06-30资产固定为权重，分别计算两个端点的代理率及变化（百分点）；各州归属按2025-06-30州别固定。与端点观察口径比较，列明进入/退出银行及其金额规模，将剩余差异称作范围和权重变化影响，不做无依据的因果拆分。
4. 分配八个互不重复的核查名额：在2025-06-30代理率有效的银行中先为VT、NH、ME各选代理率最高者，再从未选银行按代理率降序补足八个；同率按CERT数值升序。给每家列当期指标、可获得的上年同季对比、原始记录定位、为什么值得查，以及针对贷款逾期/分类、房地产集中、盈利或资本的具体补证。代理指标高不直接等于银行违规或将倒闭。
5. 使用FDIC贷款手册解释最重要的复核关注点及代理指标的局限，给委员会区分“已算出的事实”“待查原因”“建议行动”，不要引用材料没有给出的监管阈值。

## 可用材料

输入仅位于只读的 `/app/input_files/`，下列全部文件均已提供。不得修改原件；联网不是完成任务的前提，不需要重新下载或更新数据。

| 文件 | 说明 |
|---|---|

## 交付

仅将最终交付文件写入 `/app/output/`。文件名精确如下，不需要另交代码、JSON或过程日志。

`credit_review.xlsx`：至少包含DataAudit、BankQuarter（原始CSV行号及计算字段）、PeerQuarter、EndpointBridge、Priority、Sources工作表。EndpointBridge展示观察口径、固定银行固定权重口径及成员变化。
`credit_review_memo.docx`：委员会复核备忘录，概括三州/区域变化、范围偏差、八家分配及手册依据，清楚区分事实和待查解释。
`follow_up_register.csv`：八家银行各一行，含顺序、CERT、州、银行名、代理率、对比和原始行号、补证请求、拟负责角色和优先期限；与Priority一致。
